# دوپامین — بازطراحی رابط کاربری

بازطراحی کامل فرانت‌اند وب‌سایت **گروه علمی آموزشی دوپامین** (dopamine24.ir) — وب‌سایت چندصفحه‌ای فارسی و راست‌به‌چپ با پلتفرم آزمون‌های خودشناسی تعاملی.

> این پروژه **بدون هیچ فریم‌ورک جاوااسکریپتی** (بدون React / Vue / Angular / Next.js) ساخته شده است:
> HTML5 معنایی + CSS3 مدرن + جاوااسکریپت خالص (ES6+) + GSAP/ScrollTrigger + Lenis + آیکون‌های Lucide + فونت وزیرمتن (لوکال).

---

## ۱) راه‌اندازی

پروژه **هیچ مرحله build ندارد**؛ کافی است یک سرور استاتیک ساده اجرا کنید:

```bash
# روش ۱ — پایتون (لینوکس/مک/ویندوز)
python3 -m http.server 3000

# روش ۲ — Node
npx --yes serve . -l 3000

# روش ۳ — VS Code
افزونه Live Server را نصب و روی index.html کلیک کنید
```

سپس مرورگر را باز کنید: `http://localhost:3000`

> نکته: به‌دلیل استفاده از localStorage برای آزمون‌ها، حتماً از طریق `http://localhost` باز کنید (باز کردن مستقیم فایل `file://` در برخی مرورگرها localStorage را محدود می‌کند).

## ۳) معماری داده‌محور آزمون‌ها (مهم)

سؤال‌ها، گزینه‌ها، وزن امتیاز، الگوریتم تعیین پروفایل و متن تحلیل نتیجه **کاملاً از رابط کاربری جدا هستند**. برای تغییر آزمون‌ها **هیچ فایل UIای را دست نزنید**:

### تغییر سؤال‌ها و گزینه‌ها
فایل `assets/js/data/assessments/disc.js` را باز کنید:

```js
questions: [
  {
    text: 'متن سؤال',
    options: [
      { label: 'گزینه ۱', scores: { D: 2, C: 1 } },  // وزن هر بعد
      { label: 'گزینه ۲', scores: { I: 2 } },
      ...
    ]
  },
  ...
]
```

### تغییر الگوریتم امتیازدهی
هر دیتاست تابع `determine(analysis)` خودش را دارد؛ مثلاً در `mbti.js` حرف برندهٔ هر جفت با مقایسهٔ امتیازها انتخاب می‌شود و در `disc.js` بالاترین بعد برنده است. تابع را عوض کنید — موتور (`engine.js`) به‌طور خودکار همان را صدا می‌زند.

### افزودن آزمون جدید
1. فایل `assets/js/data/assessments/my-test.js` بسازید با همان ساختار (id, title, questions, dimensions, determine, profiles).
2. در `index.js` آن را به `_order` اضافه کنید.
3. در ۴ صفحهٔ `assessments.html / assessment.html / quiz.html / result.html` یک خط `<script>` برای فایل جدید اضافه کنید.

فهرست آزمون‌ها، صفحهٔ معرفی، رابط سؤال‌ها و گزارش نتیجه **به‌صورت خودکار** ساخته می‌شوند.

### ذخیره‌سازی
- `dpa_progress_<id>` → پاسخ‌ها و سؤال جاری (ادامهٔ آزمون نیمه‌تمام)
- `dpa_result_<id>` → پروفایل نهایی و امتیازها
- هیچ اطلاعات شخصی ذخیره نمی‌شود؛ همه‌چیز فقط روی مرورگر کاربر است.

## ۴) تغییر محتوای سایت

تقریباً تمام متن‌ها (منوها، دپارتمان‌ها، تیم، آمار، مقالات، سوالات متداول، اطلاعات تماس) در **`assets/js/data/site.js`** هستند. مثلاً:

```js
DPA.site.stats = [
  { value: 150, suffix: '+', label: 'رتبه زیر صد کنکور', icon: 'trophy' },
  ...
];
```

تغییر دهید و صفحه رفرش شود — نیازی به دست‌زدن به HTML نیست.

## ۵) افزودن صفحهٔ جدید

1. یکی از فایل‌های فعلی را به‌عنوان الگو کپی کنید (مثلاً `services.html`).
2. `data-page` روی `<body>` را یکتا کنید (برای هایلایت منو).
3. بلوک `<script>`های انتهای فایل را نگه دارید و در صورت نیاز `page.js` را رندرکنندهٔ جدید به آن اضافه کنید.

## ۷) سیستم موشن

توکن‌های زمان‌بندی واحد (در `base.css` و `app.js` هماهنگ):
`dur-1 = 160ms` میکرو • `dur-2 = 260ms` هاور/رابط • `dur-3 = 420ms` ورود • `dur-4 = 700ms` سکانس‌ها

انیمیشن‌های ورود با اتریبیوت‌ها فعال می‌شوند:
- `data-reveal` → fade + rise
- `data-reveal-group` → ورود پلکانی فرزندان
- `data-words` → ورود کلمه‌به‌کلمهٔ تیتر
- `data-count` → شمارندهٔ عددی (ارقام فارسی)
- `data-draw` → رسم مسیر SVG

پارالاکس و اسکرول نرم (Lenis) فقط دسکتاپ؛ `prefers-reduced-motion` کامل رعایت شده است.

## ۸) نکات فنی و محدودیت‌ها

- **فرم‌ها نمایشی هستند** (بدون بک‌اند): اعتبارسنجی سمت کلاینت دارند و پس از ارسال، پیام نمایشی می‌بینند. اتصال به API در آینده فقط در `DPA.bindForm` (فایل `app.js`) لازم است.
- تمام محتوای واقعی (تلفن‌ها، آدرس مشهد، آمار ۱۵۰ رتبه زیر صد، تیم، خدمات، مقالات) از ممیزی سایت رسمی dopamine24.ir استخراج شده است؛ هیچ داده‌ای جعل نشده است.
- آزمون‌های ۵ سؤالی **ابزار آموزشی خودشناسی** هستند و در خود رابط کاربری به‌صراحت از اعتبار بالینی آن‌ها تفکیک شده است.
- کتابخانه‌ها به‌صورت لوکال vendored شده‌اند؛ پروژه بدون اینترنت هم کامل کار می‌کند.

## ۹) دسترسی‌پذیری

ساختار معنایی، ناوبری کیبورد (از جمله انتخاب گزینه‌ها با کلیدهای ۱ تا ۴ و Enter در آزمون‌ها)، حالت فوکوس قابل‌مشاهده، ARIA برای آکاردئون/دراور/پیشرفت آزمون، skip-link و کنتراست مناسب رنگ‌ها.
